# うーちーの季節

ソフトクリームを持ったうーちーの散歩を、そっと見守る観察ゲーム。

うーちーは自分の気持ちで歩きまわります。気になるところをタッチすると、うーちーが行く…かもしれません。

## 遊び方

- ターミナルから、夏 → 秋 → 冬 → 春 の順に季節をめぐります
- 各季節に「季節のカケラ」が10個。5個集めると次の季節へのトンネルがひらきます
- 集めたカケラは「手帳」でいつでも見られます
- 「見上げる」ボタンで、うーちーといっしょに空を見上げられます
- つづきから遊ぶときは、いつもターミナルから

## 操作

| 操作 | 内容 |
| --- | --- |
| タップ / クリック | 気になるところを教える（ターミナルでは素直に行く） |
| ドラッグ | 見回す |
| ホイール | ズーム |
| 手帳 | カケラの図鑑 |
| 見上げる | 空を見上げる |

## 動かし方

`index.html` 1枚で動きます（モデルとテクスチャは埋め込み済み）。
three.js と フォントは CDN から読み込むため、ネット接続が必要です。

ローカルで開く場合：

```sh
python3 -m http.server
# http://localhost:8000 を開く
```

GitHub Pages の場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定するだけで公開できます。
